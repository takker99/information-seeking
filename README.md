# 情報探索Wiki

**Information Seeking**

知りたいことを明らかにするために、人・資料・現地での観察・デジタル検索・LLMなどをどう組み合わせるかを、実例から研究・改善するWikiです。

## 目的

特定の検索サービスを推奨する一覧ではなく、問いの目的や制約に応じた情報源・探索経路の選択と組み合わせ方を学びます。LLMは探索を助ける中心的な道具の一つですが、Web検索だけに範囲を限定しません。

## 対象

- 人への質問、図書館員や専門家への相談
- 書籍、図書館カタログ、アーカイブ、現地での観察・実験
- 一般Web、公式資料、オンラインコミュニティ
- 学術データベース、論文検索API、引用追跡
- LLM検索、Deep Research、検索・抽出API

## ケースの進め方

1. 実際に知りたい問いと、情報を使う目的・制約を明確にする。
2. Wikiの既存事例を参考に探索経路を選び、作業中に検索語・経路変更・見つかった資料・失敗・時間や費用を短く記録する。
3. 問いへの回答とソースの編み込みは、依頼元のWikiや成果物で完了する。
4. 完了後、そこで使った探索経路を一件のケースとしてこのWikiに記録する。ドメイン知識を丸ごと複製せず、方法の有効条件と限界を残す。

ツールの公式説明と、実際の問いで観察した検索品質は区別します。機能・利用条件には出典と確認日を付け、ケースで試すまでは「最適」と結論しません。
