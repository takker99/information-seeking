# Exa Search API

Exa `/search` endpointの公式API reference。

## 要点

- Web検索と、検索結果URLからの本文抽出を一つのAPIで行える。
- `auto`、`fast`、`instant`、`deep-lite`、`deep`、`deep-reasoning`等の検索typeと、publication等のcategoryを指定できる。
- 検索結果に加えて、本文/highlightsや、schemaを指定した合成出力・grounding情報を要求できる。
- 深い検索や合成出力はベンダーが説明する機能であり、引用の正確さや他サービスより高い網羅性は別途検証が必要。
