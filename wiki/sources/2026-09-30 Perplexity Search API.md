# Perplexity Search API

Perplexity開発者向けSearch APIのquickstart。

## 要点

- Search APIは、順位付きWeb検索結果を構造化データとして返し、domain/language/region等の絞り込みやcontent extractionを提供する。
- ドキュメントは、生の検索結果を自前で処理する用途にはSearch API、引用付きLLM回答には別のAgent APIを案内している。
- 消費者向けPerplexityサービスとAPIの機能・料金・契約が同一とは、このページからは言えない。別々に確認する必要がある。
