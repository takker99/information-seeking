# OpenAlex API

OpenAlexの公式REST API reference。

## 要点

- works、authors、sources、institutions等を結ぶ学術情報datasetをHTTP APIで検索できる。
- entityごとにlist/filter/search/sort/group/page等を利用でき、基本的な利用はAPI keyなしで試せる。負荷や料金条件は利用時に確認する。
- これは学術成果の発見・書誌情報の操作を支えるAPIであり、検索結果が全文入手や査読済みであることを保証するものではない。
- APIのデータ・利用条件は公式ページに基づいて確認する。
