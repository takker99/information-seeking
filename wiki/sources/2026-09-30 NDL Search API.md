# 国立国会図書館サーチAPI

NDL SearchのAPI仕様概要と利用条件。

## 要点

- 検索用にSRU、OpenSearch、OpenURL、メタデータ収穫用にOAI-PMHを提供する。現行の日本語仕様書は2026-09-25付の第1.5版。
- APIで取得できるのは、データ提供機関から許諾されたmetadataに限られる。
- 利用条件はproviderごとに異なり、営利利用や継続アクセスでは申請・事前連絡が必要な場合がある。具体的な用途ごとにprovider一覧と利用規約を確認する。
