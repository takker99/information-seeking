# CiNii Web API

国立情報学研究所のCiNii metadata/API概要。

## 要点

- OpenURL、OpenSearch、RDF、JSON-LDを提供し、論文・図書/雑誌・著者・図書館等の検索やmetadata連携に使える。
- OpenSearchの検索種別にはCiNii Researchの論文検索、図書館検索、所蔵検索、CiNii Booksの図書・雑誌や所蔵検索などがある。
- API利用登録が必要で、商用利用では事前連絡が求められる。CiNii Booksの一部metadataはCC BY 4.0で公開されるが、すべてのデータ・内容説明が自由利用できるわけではない。
