# 未知異分野の発見（意味近接×引用不在）

指定した2分野の接続を確かめる検証モードに対して、こちらは対象を指定しない発見モード。「ほぼ同じ現象を研究している未知の異分野を探す」問題で、引用ネットワークは繋がりを見せず、用語が違うためキーワード検索も引っかからない状態から候補分野を列挙する。出典は[[2026-10-28 引用断絶検出手法のsubagent相談（PGE-2026A）]]。手法の評価は文献とDB仕様の確認までで、発見パイプラインの実行実績は無い。候補ペアを指定した後の検証は[[引用ネットワーク断絶の検出手法]]。

## 発見モードで使える技法

| 技法 | 発見モードでの使い方 | 限界 |
|---|---|---|
| LBDと多言語embedding（LaBSE、multilingual-e5等） | 自分の分野の文書をembeddingし、意味が近いのに引用・co-citation構造が無い文献群を全域から拾う。用語を共有しなくてよい | 用語断絶でembedding接続が弱くなる。LBDには「発見が実作物にならない」問題（Moreau & Yamanishi 2023）があり、実用の新規性出力は低い可能性がある |
| science overlay mapsのゼロセル列挙 | 分野レベルのcitation flowマトリクスから、ほぼゼロかつ対称なセルを列挙し、意味近接フィルタで絞る | ペア指定不要の唯一の体系的手法だが、粒度が分野レベルで粗い。マトリクス作成の手間が重い |
| sleeping beautyの王子分析 | 長く眠っていた文献が目覚めた時、目覚めさせた側の所属分野を見る。現象を共有しながら語彙を持たなかった異分野を遡って特定できる | 事後発見限定。観測窓内で目覚めたものだけが対象で、永遠に眠るものは拾えない |
| 研究フロントの孤立クラスタ検出（Shibata–Kajikawa系） | 自分の分野のcitation graph内で、主流に接続しないクラスタを検出する | 分野内の孤立しか見えない。1950〜80年代和文のメタ欠落で日本側の精度が落ちる |
| LLM系LBD、knowledge graph link prediction | embeddingで弱い領域をLLMの文書読解で補う。TransE系のmissing link予測 | 発展途上で、単独での検証例が少ない |

## 発見モードに不適な手法

co-citation、bibliographic coupling、main path analysis、CiteSpace、disruption index、atypical combinationは引用事象を前提とするため、引用されていない未知の側を本質的に見えないままにする。発見モードでは引用ベースの指標を候補の発見に使わず、検証段階にのみ使う。

## 現実の組み合わせ

1. 自分の分野のwiki・概念ページ群を意味の種にする。embeddingまたはLLMの関連度判定の入力にする
2. overlay mapsのゼロセル列挙で分野レベルの候補を広く出し、1の意味近接で絞る
3. sleeping beautyの王子分析で、既に起きた発見の遅れから異分野を遡る
4. 候補が具体化したら検証モードに切り替え、レビュー参考文献スキャンと名寄せ検査で断絶を確定する

Mogami事例は機械を使わない発見モードの実例である。2分野のwiki突き合わせという手作業diffが、sleeping beautyやLBDを動かす前に断絶そのものを見つけた。wiki比較が粗探し、embeddingとoverlay列挙が本探しという分担になる。

## 縮小版パイロットの手順

以下は未実行の提案である。本格パイプラインは全域embeddingとflowマトリクス作成を要するため、subagentパイロットは縮小版で行う。

1. 種となる分野の概念・キーワード群を決める。用語の直訳を検索語にしない
2. OpenAlexの近傍topicから複数分野の文献サンプルを数百件取り、LLMで「同一現象の別表現」を探させる
3. 候補分野ごとに、種側との引用の有無をAPIで確認する
4. 汚染管理: agentの一般知識で有名なペアを「発見」として提出していないか、根拠の出自を確かめる
