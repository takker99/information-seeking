# content typeで探索先を選ぶ

検索に入る前に「どんな種類の資料が必要か」を同定し、それに合うdatabase・guideを選ぶ手続き。探索の入口を問いからではなく資料種から決める。

手順 ([[2026-09-30 Illinois Library Search Strategies]]):

1. Library Guides homepageでトピック/方法に合うguideを探す。LibGuidesは分野別databaseの入口。
2. 必要なcontent typeを同定: 背景情報、グラフ・統計・地図・media・conference proceedings、primary/secondary research、raw data。
3. トピック×資料種からdatabaseを特定。A-Z Databases listをsubject・type・vendorで絞る。迷ったらsubject specialist librarianに相談。
4. 選んだdatabaseごとに検索エンジンの強み・弱みを把握する: 著者名のフォーマット要件、関連語も一緒に検索するオプションの有無、どの分野を収録するsubject-specific databaseか。Helpとindexing documentationを読む。

Helsinki guideの「結果が多すぎ/少なすぎるときのdatabase切替」と接続する。databaseは同質な道具ではなく、資料種と収録範囲が違い、選択自体が探索戦略の一部。
